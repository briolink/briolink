- **2026-10-14** — Created the OCI Bastion `Bastion202610141417` (console, by hand; target subnet `public subnet-briolink-vcn`), CIDR allowlist restricted to the tower's public IP (`65.38.69.115/32` at the time — update if the tower's residential IP rotates). Fixed by adding a scoped ingress rule — `10.0.0.0/24 → TCP 22` (the subnet the Bastion targets), not `0.0.0.0/0` — to the default security list. Confirmed working: SSH via the Bastion tunnel as `ubuntu@10.0.0.226` (aarch64).
