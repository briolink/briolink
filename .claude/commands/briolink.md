In Claude Code the hook (`scripts/briolink.sh --hook`) answers `/briolink`, `/briolink list`, `/briolink tidy` and `/briolink exit` itself, without a model turn, and binds the session and switches the `gh` account for every other form before this text reaches you. Without that hook (another tool), run `scripts/briolink.sh` with the arguments (`bind` for a role or task form, nothing for the board) and print its output verbatim; do nothing else for the board, `list`, `tidy` or `exit`.

Read `agents/master.md` if it is not already in the context, and follow its "Session and roles".
- `done`: close the piece of work. Check `git status` and unpushed commits; commit and push what belongs to the work; save to the repo anything of the work still only in a scratchpad or `/tmp` (prototypes, measurements, scripts, drafts); write any decision or open point the conversation holds into the docs, an issue, or the roadmap. An issue left waiting on a date or an outside event gets `state:waiting` and a `Waiting until <date>: <reason>` line in its body; remove both once it no longer waits. An issue whose role is decided gets its `role:<name>` label. For each issue the work closed, find the open `state:blocked` issues whose **Dependencies:** line names it; when every dependency that line names is met (issues closed, anything named in words checked or asked), replace `state:blocked` with `state:queued`. Once the work's pull request is merged (or nothing is open), run `scripts/briolink.sh tidy`; act on what it reports as yours to fix (a missing `state:` label or milestone on an issue this work touched) and leave the rest in the reply. Rewrite the roadmap's Now section: Last (date, one line, the IDs or links touched) and Lead (one line, phrased as a suggestion; once issues exist, it links the issue). Run `scripts/session-usage.sh` last and end the closing commit's message with its output as a `Usage: ` line. Then reply with a short list of where everything was saved and what was left out, the usage line, and end with: `Saved. Run /clear to start the next piece of work fresh.` Never clear with anything unsaved.
